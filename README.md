I like making things, taking them apart, and figuring out how they work. That can mean a website, a radio receiver, a PCB, a bit of car electronics, or a security rabbit hole.

Much of my open-source work connects hardware to the browser. I enjoy making radio and networking tools easier to use, while keeping the interesting details within reach.

## Main projects

| Project | What it does | Try it |
| :--- | :--- | :--- |
| 📻 **[BrowSDR](https://github.com/jLynx/BrowSDR)** | A browser-based SDR receiver with direct WebUSB access, Rust and WebAssembly signal processing, and tools for exploring and decoding radio signals. | [Open BrowSDR](https://browsdr.jlynx.net/) |
| 📡 **[PortaPack Mayhem](https://github.com/portapack-mayhem/mayhem-firmware)** | Community-developed firmware for HackRF and PortaPack devices. I contribute firmware improvements and supporting tools, including work on firmware flashing. | [Latest firmware](https://github.com/portapack-mayhem/mayhem-firmware/releases/latest) |
| 🌐 **[Mayhem Hub](https://github.com/portapack-mayhem/MayhemHub)** | A browser-based dashboard for HackRF and PortaPack Mayhem, with live screen streaming, remote control, SD card file management, and firmware updates through Web Serial. | [Open Mayhem Hub](https://hackrf.app/) |
| 🔌 **[Pocketweb for Pockethernet](https://github.com/jLynx/Pockethernet-Web)** | An independent, open-source app for Pockethernet 2. Cable diagnostics, network testing, and shareable PDF reports, connected through Web Bluetooth. | [Open Pocketweb](https://pockethernet.jlynx.net/) |

## What I work with

**Software:** TypeScript, Rust, C/C++, Vue, React, and WebAssembly.

**Hardware:** SDR, firmware, PCBs, automotive electronics, CAD, and 3D printing.

If it has a compiler, a datasheet, or a serial port, I'll probably end up using it.
